How the value is built

implied value = TVL × peer multiple × growth multiplier × maturity multiplier × breadth multiplier

  • Peer multiple — the median FDV/TVL (market cap / TVL) of live-token protocols in the same category, used only when the category has at least 3 live peers; otherwise the global median. Clamped to 0.05–3.0.
  • Growth multiplier — 1 + clamped 7-day change × 0.35. The 7-day change is clamped to −50% … +150%; a missing change counts as 0%.
  • Maturity multiplier — 0.7 + 0.3 × (1 − e−age/365), where age is the days from first listing to the snapshot date; 0.85 when the listing date is unknown.
  • Breadth multiplier — 1 + 0.02 × min(chains − 1, 5).

Method

  • Who ranks: protocols that record no token and are not set aside. Live-token protocols never appear on the board; they are shown separately below as the comparison set the peer multiples come from.
  • Who is set aside: bridges and wrapped products, liquid-staking products, centralized exchanges, exchange-named products and versioned releases (for example a name ending in V2). They are listed below with their reason.
  • Records no token, never has none: DefiLlama’s record is not proof a token does not exist.
  • Frozen snapshot: every run reads the same sealed snapshot, so the same figures give the same board.
